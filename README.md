# RICH (Rice Check) - Deteksi Penyakit Daun Padi

RICH adalah proyek Deep Learning berbasis Computer Vision yang dirancang untuk mengklasifikasikan jenis penyakit pada daun padi secara otomatis. Proyek ini menggunakan model Convolutional Neural Network (CNN) yang disajikan dalam bentuk antarmuka web interaktif menggunakan Streamlit.

🚀 Versi Aplikasi Demo
Repositori ini khusus dibuat untuk menjalankan aplikasi demo secara cepat di Streamlit Cloud. Semua file utama dan bobot model terbaik (best_rice_disease_model.Keras) diletakkan langsung di halaman utama untuk memastikan performa aplikasi yang ringan dan instan.
